## 💡 Challenges & Solutions

### 📊 역량 강화 리포트 (Competency Enhancement Report)

**[Challenge] 고정된 데이터 구조로 인한 확장성 한계**
* **문제 상황:** 초기 설계 시 학습 콘텐츠의 '유형'과 '난이도'를 고정된 상수로 정의하고 태그만 추가하는 방식을 채택했습니다.
* **기술적 판단:** 개발 진행 중, 기업마다 서로 다른 교육 체계와 평가 기준(난이도)을 가지고 있다는 점을 파악했습니다. 기존의 정적인 구조로는 다양한 기업 요구사항에 대응하기 어렵고 유지보수 효율이 떨어진다는 결론을 내렸습니다.

**[Solution] 동적 커스터마이징이 가능한 유연한 구조 설계**
* **해결 방안:** 각 기업 관리자가 서비스 환경에 맞춰 학습 콘텐츠의 **유형(Type)과 난이도(Level)를 직접 정의하고 관리**할 수 있도록 시스템 구조를 전면 개편했습니다.
* **결과:** 특정 기업에 종속되지 않는 범용적인 HR 플랫폼으로서의 확장성을 확보하였으며, 데이터 모델링 최적화를 통해 새로운 속성 추가 시에도 코드 수정 없이 유연한 대응이 가능해졌습니다.

### 💰 연봉 관리 및 결재 시스템 (Salary Management & Approval)

**[Challenge] 복잡한 보상 데이터의 시각적 한계 및 가독성 저하**
* **문제 상황:** 누적된 연봉 데이터와 다양한 성과급 항목을 단순 테이블 수치로만 나열하여, 인사관리자가 기본급과 보상 급여의 변화 추이를 직관적으로 파악하는 데 한계가 있었습니다.
* **기술적 판단:** 텍스트 위주의 UI는 데이터 양이 많아질수록 가독성이 급격히 저하되므로, 데이터의 흐름을 효과적으로 전달할 수 있는 시각화 라이브러리 도입이 필수적이라고 판단했습니다.

**[Solution] Chart.js 기반의 5개년 보상 통계 대시보드 구축**
* **문제 상황:** Chart.js를 연동하여 평면적인 데이터를 시계열 그래프로 전환했습니다. 5개년 연봉 추이뿐만 아니라, 변동 보상 관리 시 해당 연도의 4가지 보상 타입별 급여를 한눈에 비교할 수 있는 통합 대시보드를 구현했습니다.
* **기술적 판단:** 복잡한 급여 구조를 직관적인 UI로 제공하여 인사관리자의 업무 편의성을 극대화하였으며, 다각도 분석이 가능한 보상 통계 기능을 완성했습니다.
