# HIT-HRadar
성과를 성장 전략으로 전환하는 HR 플랫폼

## 🚀 My Role & Contributions

### 🧱 공통 모듈 및 코드 관리 (Common Modules & Core)
* 직무, 상태값 등 기초 데이터를 중앙 집중 관리하여 **데이터 일관성을 확보 및 유지보수 효율 극대화**
* 기업별 인사 가이드에 맞춰 **학습 콘텐츠 유형(Type) 및 난이도(Level) 커스터마이징 구조**를 설계
* 동료 코드 리뷰 수행 및 공통 API 가이드 제공을 통해 전체 코드 품질 및 개발 컨벤션 유지
  
### 📊 역량 강화 리포트 (Competency Enhancement Report)
* 직접 분석 기간을 설정하여 원하는 시점의 성과를 유연하게 리포트로 생성할 수 있는 기능 구현
* 역량-태그-콘텐츠 간의 **N:M 관계 모델링**을 통해 개인별 부족 역량에 최적화된 맞춤형 학습 콘텐츠 추천 로직을 구현
* **OpenAI API**를 연동하여 KPI/OKR 달성 결과 및 원인을 분석하고, 사후 액션 플랜 리포트 생성 자동화
* 역량 분석 데이터를 체계적으로 관리하기 위한 리포트 전용 엔티티 설계

### 💰 연봉 관리 및 결재 시스템 (Salary Management & Approval)
* `Chart.js`를 활용한 **5개년 연봉 추이 및 변동 보상** 시계열 통계를 구현으로 인건비 인사이트 제공
* 기본급(Base Pay)과 변동 보상(Variable Pay)을 분리 설계하여 기업별 다양한 **급여 정책에 유연하게 대응** 가능
* 전사 공통 결재 시스템의 결재 워크플로우 설계 지원
